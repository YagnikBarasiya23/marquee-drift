# Studio Current art direction

Eight original, flat, geometric fictional wordmarks: morrow, fieldwork, arcwell, softform, northline, stillroom, kindred, openair. Forest ink (#23392d), transparent background, no baked shadows. Logical size 160×48; PNG output 320×96. One logo per file.

These simple geometric assets are authored as editable SVG and rasterized by `node scripts/art.js` using Chromium, rather than generated bitmap art. Source and PNG files are retained together. Geometric motifs: folded M, field bars, arch, paired soft squares, north chevron, still verticals, branching K, overlapping open circles. Names are fictional demo content, not trademark-clearance claims.
